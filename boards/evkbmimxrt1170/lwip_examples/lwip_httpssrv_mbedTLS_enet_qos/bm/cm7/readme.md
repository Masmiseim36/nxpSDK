# lwip_httpssrv_mbedTLS_enet_qos_bm

## Overview

The lwip_httpsrv_mbedTSL_bm demo application demonstrates an HTTPS server set up
on lwIP TCP/IP and the mbedTLS stack with bare metal. The user uses an Internet
browser to send an https request for connection. The board acts as an HTTPS
server and sends a web page back to the PC.
