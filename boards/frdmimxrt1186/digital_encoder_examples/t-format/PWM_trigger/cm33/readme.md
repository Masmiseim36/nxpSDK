# t-format_PWM_trigger

## Overview
The t-format_PWM_trigger example shows how to use flexio T-format driver in sync way:

In this example, a flexio simulated T-format connect to the encoder through RS-485, the board
will send requests triggered the FlexPWM to and receive responses from the board.
